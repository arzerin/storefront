# Smart-minima-commerce

This is the original Ayra storefront theme. `theme.info.json` describes it to the admin theme manager. The base design lives in `resources/css/ayra.css`; `theme.css` is an intentionally small override layer.

Page builder templates live in `views/site-builder/pages/` and are shared by all storefront themes. Theme activation changes the customer-facing design across homepage, product, cart, checkout, order, account and content pages. It does not change page content.

For upload format and CSS hooks, see `resources/themes/README.md`.
